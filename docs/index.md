# pkgguard API

**pkgguard is an AI package security API and pre-install dependency gate for
npm, PyPI, and crates.io.** It detects package hallucinations, slopsquatting,
typosquatting, conflated package names, and suspicious new dependencies before
an AI coding agent or CI pipeline runs an install command.
